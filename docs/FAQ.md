# FAQ

**Is this GTA VI?** No. This is an independent original top-down prototype with no official relationship to Rockstar.

**Does it include leaked CyberLeak/Cyberleek files?** No. The repository contains no leaked assets or proprietary source material.

**Is it playable?** Yes, it includes a small keyboard-driven 2D game prototype, not a complete commercial title.

**Is this 3D?** No, it uses HTML5 Canvas 2D.

**Is there multiplayer?** No.

**Are the police real AI?** No. The wanted level is currently a HUD/state mechanic only.

**Does it have nine missions?** Yes, nine sequential waypoint tasks of travel, driving and timed types. They are not scripted story missions.

**Can I record actual game footage?** Yes. Run the site and record the screen. AI-generated videos must remain labeled concept footage.
