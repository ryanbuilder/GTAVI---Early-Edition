# Release process

## Before publishing
1. Verify repository license and source asset rights.
2. Run `npm install`, `npm run check`, `npm test`, `npm run build`.
3. Complete the manual QA checklist and record known issues.
4. Tag a release with semantic versioning and a date.
5. Explain exactly which mechanics work and which are planned.
6. Label AI-generated mockups as concept footage. Gameplay claims require real capture from the working build.

## Distribution
GitHub source can be hosted as a static site after the Vite build. Do not call a concept video a gameplay recording. Do not distribute leaked proprietary content or third-party copyrighted assets without authorization.
