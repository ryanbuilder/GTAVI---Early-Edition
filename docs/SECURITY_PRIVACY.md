# Security and privacy

No server, login system, analytics SDK, payment processing or external account access ships with this browser prototype. The app stores game progress locally using localStorage. No personal information should be added to game saves.

The repository must not contain proprietary game leaks, copyrighted ripped assets, credentials or claims of Rockstar affiliation. Report vulnerabilities privately to the repository maintainers when contact information becomes available.

Future online features require an explicit threat model, authentication design, server-authoritative state, API rate limits and privacy review. Client-side save data cannot be trusted for multiplayer economies.
