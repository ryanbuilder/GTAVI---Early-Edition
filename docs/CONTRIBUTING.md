# Contributing

Open a focused issue before proposing large gameplay changes. Branch from `main`, keep pull requests small, and describe observable behavior plus manual reproduction steps.

## Code guidelines

- Prefer readable functions and deterministic simulations.
- Avoid undocumented external dependencies or data collection.
- Include a manual test plan for interaction, collision, saves and performance changes.
- Do not claim a feature exists until it runs in the submitted build.
- Keep README, roadmap and legal/provenance notes accurate.

## Assets and intellectual property

Contribute only original assets or material you are entitled to redistribute. Do not add confidential game source, unreleased commercial game files, rips from copyrighted games, or misleadingly labeled AI concept footage.
